# Project Instructions for Claude Code

Цей проєкт — універсальний стартовий набір агентських скілів для побудови та наповнення Бази Знань проєкту в Notion.

## Спеціалізовані скіли (Skills Directory: `.agents/skills/`):
- `notion-project-init`: створення ієрархії сторінок та бази даних у Notion «з нуля».
- `knowledge-base-manager`: головний координатор та диспетчер матеріалів.
- `requirements-normalizer`: декомпозиція сирих вимог (MD, DOCX, GDoc, Jira, Confluence, чат) до атомарних REQ-* без додумування від себе.
- `requirements-analyzer`: аудит вимог на дефекти. Якісні -> `узгоджено` + `Ким підтверджено: AI Agent`. Проблемні -> у таблицю Розділу 2 з відкритими питаннями.
- `requirements-resolver`: генерація локальних опитувальних анкет для стейкхолдерів у `clarifications/` (поза контролем Git).
- `requirements-decision-applier`: зчитування відповідей з `clarifications/*.md`, оновлення стану на `узгоджено` та встановлення позначки `✅ Вирішено` в Розділі 2.
- `openapi-spec-generator`: створення специфікацій OpenAPI 3.0+ на базі Swagger UI/схем та оновлення Розділу 5.

## Головні обмеження:
1. **Незмінність суті**: ніколи не додумувати умови та не змінювати бізнес-логіку під час нормалізації.
2. **Заборона самовільних рішень**: при виявленні дефектів у вимогах агент лише формулює відкриті запитання та варіанти, але не обирає рішення сам.
3. **Безпека Git**: усі чернетки та анкети опитувань зберігаються виключно в папці `clarifications/`, яка внесена до `.gitignore`.
4. **Мова**: уся документація, спілкування та артефакти ведуться українською мовою.
